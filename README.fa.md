برای اتصال، حساب یکی از سرویس‌های VPN پشتیبانی‌شده را لازم دارید. فایل دانلودی نام کاربری یا رمز عبور ندارد. اپ ویندوز با Surfshark و Windscribe کار می‌کند. مراحل لینوکس زیر با فایل‌های OpenVPN سرویس Surfshark که در مخزن هستند نوشته شده‌اند؛ فایل‌های `.ovpn` سرویس خودتان را هم می‌توانید داخل `configs/` بگذارید.

## نصب اپ Relay در ویندوز

### ۱. دانلود

1. صفحهٔ [آخرین نسخهٔ منتشرشده](https://github.com/120hdd/ovpn-pin/releases/latest) را باز کنید.
2. از بخش **Assets**، فایل `Relay-windows-x64-….zip` را بگیرید. اگر می‌خواهید سالم‌بودن دانلود را بررسی کنید، فایل همنام با پسوند `.zip.sha256` را هم بگیرید. گزینهٔ **Source code** اپ آمادهٔ اجرا نیست.
3. روی فایل ZIP راست‌کلیک کنید و **Extract All** را بزنید. پوشهٔ استخراج‌شده‌ای را که `Relay.exe` داخل آن است باز کنید. فایل‌های داخل آن را جدا نکنید.

برای این روش به Git، Python یا نصب‌کننده نیاز ندارید.

<details>
<summary>اختیاری: بررسی فایل دانلودشده</summary>

فایل ZIP و فایل `.sha256` را در یک پوشه بگذارید. PowerShell را در همان پوشه باز کنید و این دو دستور را بزنید:

```powershell
Get-FileHash .\Relay-windows-x64-*.zip -Algorithm SHA256
Get-Content .\Relay-windows-x64-*.zip.sha256
```

دو مقدار طولانی نمایش‌داده‌شده باید یکسان باشند. چون برنامه امضای دیجیتال ندارد، ممکن است Windows SmartScreen هشدار بدهد. پس از بررسی نسخه و هش، برای اجرا **More info → Run anyway** را بزنید.

</details>

### ۲. افزودن حساب

1. داخل پوشهٔ استخراج‌شده، `Relay.exe` را اجرا کنید.
2. روی علامت چرخ‌دنده بزنید؛ در **Accounts**، گزینهٔ **Add an account** را انتخاب کنید.
3. سرویس خود را انتخاب کنید:
   - **Surfshark:** نام کاربری و رمز **Service credentials** را از صفحهٔ تنظیم دستی Surfshark بردارید. ایمیلی که با آن وارد سایت می‌شوید، نام کاربری این بخش نیست.
   - **Windscribe:** با حساب Windscribe وارد شوید و مرحله‌ای را که برنامه نشان می‌دهد کامل کنید.
4. در **Connect through**، سرویس اضافه‌شده را انتخاب کنید. نسخهٔ آماده چند کانفیگ اولیه دارد که IP آن‌ها از قبل پین شده است. برای گرفتن فهرست کامل‌تر یا تازه‌تر، مرحلهٔ بعد را انجام دهید.

### ۳. پین‌کردن IP و کانفیگ‌ها

هر وقت سرورهای جدید دریافت کردید یا فایل `.ovpn` خودتان را اضافه کردید، این مرحله را انجام دهید. داخل کانفیگ دانلودشده معمولاً نام سرور نوشته شده است. عملیات Pin، IP عمومی آن را پیدا می‌کند و یک کپی از کانفیگ می‌سازد که در خط `remote` آن IP قرار دارد. برای اتصال از **کپی پین‌شده** استفاده کنید، نه فایل دانلودشدهٔ اولیه.

1. در **Settings → Accounts**، روی کارت سرویس خود **Get servers** یا **Update servers** را بزنید تا فایل‌های `.ovpn` آن دریافت شوند. اگر فایل `.ovpn` را خودتان دارید، آن‌ها را در یک پوشه نگه دارید.
2. به **Settings → Servers → Pin them to real addresses** بروید. بخش **From** باید پوشهٔ کانفیگ‌های اصلی را نشان بدهد. اگر پوشهٔ دیگری است، **Change…** را بزنید و پوشهٔ درست را انتخاب کنید. تعداد کانفیگ‌های آماده در همین صفحه نمایش داده می‌شود.
3. در بخش **Over**، اگر پراکسی محلی ندارید **Straight out** را انتخاب کنید. اگر DNS-over-HTTPS مستقیم جواب نمی‌دهد و از قبل یک پراکسی HTTP محلی دارید، **Through a proxy** را انتخاب کنید و پورت واقعی آن را کنار `127.0.0.1` بنویسید. پراکسی فقط برای پیدا کردن IP استفاده می‌شود.
4. بخش **Into** را روی پوشهٔ پیش‌فرض `pinned` بگذارید. گزینهٔ بررسی دسترسی IPها را روشن نگه دارید؛ سپس **Pin** را بزنید و تا پیام **Done** صبر کنید. مطمئن شوید که برنامه تعداد فایل‌های ساخته‌شده را بیشتر از صفر نشان می‌دهد. از هر کانفیگ ممکن است چند کپی برای IPهای مختلف ساخته شود؛ فایل اصلی تغییر نمی‌کند.
5. کانفیگ‌های پوشهٔ پیش‌فرض `pinned` خودکار به فهرست سرورهای Relay اضافه می‌شوند. اگر برای **Into** پوشهٔ دیگری انتخاب کردید، بعد از پایان کار **Connect through these** را بزنید.

اگر دکمهٔ **Pin** غیرفعال است، مطمئن شوید داخل **From** فایل `.ovpn` وجود دارد و در حالت **Through a proxy** پراکسی روی پورت نوشته‌شده روشن است. اگر هیچ فایلی ساخته نشد، علت را در نتیجهٔ هر کانفیگ بخوانید و بعد سراغ اتصال بروید.

### ۴. اتصال

1. تنظیمات را ببندید و مسیر **Provider** را انتخاب کنید.
2. در **Exit location** یک کشور انتخاب کنید، یا **Whichever answers first** را برای انتخاب خودکار نگه دارید.
3. **Connect** را بزنید. پس از اتصال، باید یک نشانی در بخش **Seen as** ببینید.
4. برای قطع اتصال، **Disconnect** را بزنید.

حساب‌ها و تنظیمات در `%LOCALAPPDATA%\Relay` ذخیره می‌شوند. بعداً می‌توانید پوشهٔ استخراج‌شدهٔ برنامه را جابه‌جا کنید.

### اگر وصل نشد

- حساب را در **Settings → Accounts** بررسی کنید. برای Surfshark باید *Service credentials* را وارد کرده باشید.
- اگر فهرست سرورها خالی است، کانفیگ‌ها را از کارت سرویس در **Accounts** دریافت کنید و طبق مرحلهٔ بالا در **Settings → Servers** پین کنید.
- اگر بعد از بسته‌شدن ناگهانی برنامه، پراکسی ویندوز روشن ماند، Relay را دوباره باز کنید و اتصال را قطع کنید تا تنظیم قبلی برگردد.

ابزارهای PowerShell ویندوز در [windows/README.md](windows/README.md) و تنظیمات پیشرفتهٔ اپ در [app/README.md](app/README.md) آمده‌اند.

## نصب در لینوکس

دستورهای نصب بسته‌ها برای Ubuntu و Debian هستند. در توزیع‌های دیگر، معادل Git، curl، OpenVPN و iproute2 را نصب کنید. همهٔ دستورها را در ترمینال بزنید.

### ۱. نصب پیش‌نیازها

```bash
sudo apt update
sudo apt install git curl openvpn iproute2 nano
```

### ۲. گرفتن فایل‌های پروژه

**با Git:**

```bash
git clone https://github.com/120hdd/ovpn-pin.git
cd ovpn-pin
```

**بدون Git:** صفحهٔ [مخزن](https://github.com/120hdd/ovpn-pin) را باز کنید، **Code → Download ZIP** را بزنید و فایل را استخراج کنید. در فایل‌منیجر وارد پوشهٔ `ovpn-pin-main` شوید، روی فضای خالی راست‌کلیک کنید و **Open in Terminal** را بزنید. باقی دستورها باید از همین پوشه اجرا شوند. این پوشه را بعد از نصب حذف نکنید؛ دستور نصب‌شده به فایل‌های همین‌جا اشاره می‌کند.

### ۳. واردکردن اطلاعات حساب

فایل‌های آمادهٔ `configs/` مربوط به Surfshark هستند. فایل نمونه را کپی کنید، دسترسی آن را محدود کنید و دو مقدار ابتدای فایل را ویرایش کنید:

```bash
cp .env.example .env
chmod 600 .env
nano .env
```

```ini
OVPN_USER=your-service-username
OVPN_PASS=your-service-password
```

برای ذخیره در nano به‌ترتیب **Ctrl+O**، **Enter** و **Ctrl+X** را بزنید. نام کاربری و رمز *سرویس* را از صفحهٔ تنظیم دستی Surfshark بردارید؛ ایمیل حساب را اینجا وارد نکنید. اگر فایل‌های `.ovpn` سرویس دیگری را دارید، ابتدا آن‌ها را در `configs/` کپی کنید و اطلاعات مخصوص OpenVPN همان سرویس را وارد کنید.

### ۴. نصب دستور و پین‌کردن کانفیگ‌ها

```bash
bash linux/ovpn install
```

این دستور `ovpn` را در `~/.local/bin` قرار می‌دهد. اگر دستور `ovpn` در همین ترمینال پیدا نشد، متن خروجی نصب‌کننده راه افزودن آن به PATH را نشان می‌دهد. تا آن موقع می‌توانید از `./linux/ovpn` استفاده کنید.

1. مطمئن شوید کانفیگ‌های اصلی `.ovpn` در پوشهٔ `configs/` هستند. فایل‌های Surfshark از قبل در مخزن وجود دارند. هنوز با فایل‌های اصلی وصل نشوید.
2. دستور پین را اجرا کنید:

   ```bash
   ./linux/ovpn pin
   ```

3. تا پایان کار صبر کنید. دستور، نام هر سرور را با DNS-over-HTTPS بررسی می‌کند، نشانی‌های غیرعمومی را کنار می‌گذارد و کپی‌هایی در `pinned/` می‌نویسد که خط `remote` آن‌ها IP عمومی دارد. از هر کانفیگ اصلی حداکثر چهار کپی مخصوص IPهای مختلف ساخته می‌شود. فایل‌های `configs/` دست‌نخورده می‌مانند.
4. پیش از اتصال، ساخته‌شدن فایل‌ها را بررسی کنید:

   ```bash
   ls pinned/*.ovpn | head
   grep '^remote ' pinned/*.ovpn | head
   ```

   در خروجی دستور دوم، بعد از `remote` باید IP ببینید، نه نام سرور. اگر هیچ فایلی ساخته نشد، خطای دستور Pin را بخوانید. اگر DNS-over-HTTPS مسدود است و از قبل پراکسی HTTP محلی دارید، `./linux/ovpn pin --proxy http://127.0.0.1:10808` را اجرا کنید و پورت را با پورت پراکسی خودتان عوض کنید.

### ۵. وصل‌شدن و قطع اتصال

```bash
./linux/ovpn connect
```

از فهرستی که می‌بینید، شمارهٔ یک سرور را وارد کنید. وقتی `sudo` خواست، رمز کاربر لینوکس خودتان را بزنید؛ OpenVPN برای ساخت اتصال به دسترسی مدیر نیاز دارد. سپس:

```bash
./linux/ovpn status
./linux/ovpn stop
```

اگر `~/.local/bin` در PATH باشد، در ترمینال‌های بعدی می‌توانید از هر پوشه‌ای `ovpn connect`، `ovpn status` و `ovpn stop` را اجرا کنید.

### اگر وصل نشد

- اگر نشانی‌های ذخیره‌شده قدیمی شده‌اند، `./linux/ovpn sync` را اجرا و دوباره تلاش کنید.
- اگر OpenVPN نام کاربری یا رمز را رد کرد، مقادیر `.env` را بررسی کنید و `./linux/ovpn pin` را دوباره بزنید.
- اگر پیام `ovpn: command not found` گرفتید، ترمینال جدیدی باز کنید یا از داخل پوشهٔ پروژه `./linux/ovpn` را اجرا کنید.

دستورها و گزینه‌های بیشتر: [linux/README.md](linux/README.md).

## راه‌اندازی سرور شخصی

این بخش اختیاری است. ابتدا مراحل ویندوز یا لینوکس بالا را انجام دهید. در اپ ویندوز، **Settings → Your own tunnel** را باز کنید و مراحل نصب سرور را که همان‌جا نشان داده می‌شود دنبال کنید. به یک سرور و یک دامنه نیاز دارید؛ نصب‌کنندهٔ سرور اطلاعاتی را که باید در Relay وارد کنید نمایش می‌دهد. دستورهای معادل برای لینوکس در [linux/README.md](linux/README.md#the-proxy-and-your-own-tunnel) هستند.
