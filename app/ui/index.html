Route all of Windows

Sets the Windows proxy so every program uses the connection. Off, it serves on 127.0.0.1:8877 and leaves the machine alone.

The port it listens on

The proxy serves here whether Windows is routed or not. Move it if something else on this machine already holds 8877.

This one port answers both HTTP and SOCKS5 — whichever a program asks for, no second port and nothing to set up. Browsers can use either. In Telegram, choose SOCKS5. On HTTP it stops tunnelling and sends a separate request per message, in the clear on port 80; on SOCKS5 it keeps one connection and is measurably quicker. No username or password — it only listens on this machine.

Pin them to real addresses

A config you download points at a hostname, and on a censored line that is the weak link: the resolver answers with an address on your own network, OpenVPN dials it, and nothing ever leaves the building. This asks over DoH instead, throws away the forged answers and writes the address into the file. A hostname with four addresses gives you four files.
