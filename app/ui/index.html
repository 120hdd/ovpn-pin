    Connect through

    Route all of Windows

    Sets the Windows proxy so every program goes through the connection. Off, nothing on the machine changes and the proxy simply waits on 127.0.0.1:8877 for whatever is pointed at it by hand.

    The port it listens on

    The proxy serves here whether Windows is routed or not. Move it if something else on this machine already holds 8877. One port answers both HTTP and SOCKS5, so there is no second port and nothing to set up, and no username or password either, because it only listens on this machine.

    Setting this up in Telegram? Pick SOCKS5 rather than HTTP. Same port, and it holds one connection open instead of sending every message separately in the clear.

    Your own tunnel

    not set

    A server you rent, reached through a CDN, carrying the traffic instead of the provider's proxy. It is here because the provider's stopped carrying uploads — measured on this line, the same file went up at 1‑10 Mbit with half the attempts dying, and 40‑80 Mbit through a tunnel.

    Nothing to do here unless you rent a server and own a domain.

    On the server, once

    Point a domain at the server on Cloudflare with the cloud on, then paste this into an SSH session as root. Copy takes the whole installer rather than just this line, so it is one paste with nothing to upload first. Safe to run twice, it leaves other sites on the box alone, and it prints the two passwords when it finishes.

    install-server.sh <domain.com> <surfshark-user> <surfshark-pass>

    Copy fills the domain in from the field below. Put your Surfshark username and password where the brackets are.

    Back in this window

    Both passwords are made by the installer and printed when it finishes. The tunnel one stops strangers who find the domain using it as an open proxy; the API one is what lets this window change the exit country. Lost them? They are on the server in /etc/gost/tunnel.pw and /etc/gost/api.pw.

    Pin them to real addresses

    A config you download points at a hostname, and on a censored line that is the weak link: the resolver answers with an address on your own network, OpenVPN dials it, and nothing ever leaves the building. This asks over DoH instead, throws away the forged answers and writes the address into the file. A hostname with four addresses gives you four files.

        Time the servers properly

        Connects to each one for real, writes how long its handshake took on the front of its name, and drops it again. That is the number the list is ordered by, and the only way to know it. Your connection goes down and up once per server, so reckon in minutes.
